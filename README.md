C# WinForms - Araç Marka, Model ve Paket ŞablonU
Bu proje, C# Windows Forms ortamında Dictionary (Sözlük) veri yapısı kullanılarak geliştirilmiş dinamik bir Marka - Model - Paket seçim ve yönetim şablonudur.

Uygulama; kullanıcıların tıkladığı markaya göre ilgili modelleri, seçilen modele göre de ilgili paket seçeneklerini anlık olarak listelemesini sağlar.

🚀 Özellikler
Bağlantılı ListBox Yapısı:

listBox1 (Marka) seçildiğinde listBox2 (Model) otomatik dolar.

listBox2 (Model) seçildiğinde listBox3 (Paket) otomatik dolar.

Dinamik Veri Ekleme: textBox1 üzerinden yeni markalar eklenebilir.

Dinamik Veri Silme: Seçilen marka listeden ve veri yapısından kolayca silinebilir.

Bellek İçi (In-Memory) Veri Yönetimi: Dictionary<string, List<string>> kullanılarak hızlı ve ilişkisel veri akışı sağlanır.
